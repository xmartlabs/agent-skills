- "preExistingCode": true on a finding means every line of the code it quotes is in the file unchanged by this pull request: the problem sits in code that was already there, even when this change is what now reaches it. It does not count toward the verdict, whatever its severity or worth. List it under "Pre-existing code (not blocking)", never under "Blocking" or "Should fix", keep its severity, append "— in code this PR did not change; worth a separate ticket", and never name it as a reason for the verdict.
